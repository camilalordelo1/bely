# Bely

Projeto acadêmico de marketplace para agendamento de serviços de beleza.

A implementação da landing page com protótipo mobile está na branch `feature/landing-mvp-duas-visoes`.

Para testar localmente, abra `index.html` no navegador a partir dessa branch. O protótipo usa dados demonstrativos e armazenamento local; as 12 entrevistas de pesquisa de campo foram reais.
